# Development install:
#
#     python3 -m venv .venv && . .venv/bin/activate
#     pip install -r requirements-dev.txt
#
# This repository no longer needs a sibling checkout to run. It used to
# install `-e ../mcuhome-workbench` and `-e ../mcuhome-cli`, because the build server
# spawned the `mcuhome` command as its builder and imported the library
# for the version it was about to spawn; both went with the job
# protocol. The build server is an orchestrator and is never itself the
# build environment, so there is no builder to install alongside it.
#
# `mcuhome-workbench` is what pyproject.toml declares, and it is a
# reversal of the older rule (see the comment there): this server no
# longer orchestrates anything, so a session's build environment is the
# workbench's rather than a second implementation of it. Neither is
# published yet, so the editable lines below satisfy the declaration
# from the sibling checkouts — the workbench from `mcuhome`, and the
# vocabulary it depends on from `mcuhome-sdk` (ADR 0024).
#
# `mcuhome-compiler` is deliberately **not** here. It is the program
# that runs inside a build container, and installing it beside this
# server would put a toolchain on a host whose whole point is not
# having one. The workbench reaches it through a dynamic import for the
# build methods that need one; nothing on this side does.
#
# There is deliberately no `mcuhome-ui` here, and no sibling
# checkout of it either: the build server depends on the build-container
# contract and on nothing else (ADR 0017 decision 3, dashboard ADR 0012).
# The frame envelope the two products share is pinned by the contract,
# not by importing one product into the other's test run.
#
# Working on this repository ALONE (no sibling checkout): satisfy the
# declaration from git instead — pip clones internally, you keep
# exactly one checkout:
#
#     pip install \
#       "mcuhome-model @ git+https://github.com/mcu-home/mcuhome-sdk#subdirectory=packaging/model" \
#       "mcuhome-workbench @ git+https://github.com/mcu-home/mcuhome-workbench" \
#       -e .[dev]
-e ../mcuhome-sdk/packaging/model
-e ../mcuhome-workbench
-e .[dev]
